Conceitos Básicos

O que é um Banco de Dados?

Pense em uma biblioteca física. Ela tem fichários, prateleiras e listas organizadas. Um banco de dados é exatamente isso — só que digital. É um lugar onde guardamos informações de forma organizada para encontrá-las rapidamente.

  • Um livro pode possuir vários exemplares físicos
  • Um exemplar pode participar de vários empréstimos ao longo do tempo

  • Cada empréstimo pertence a exatamente um exemplar
  • Cada exemplar pertence a exatamente um livro
DDL — Definição

Criando as Tabelas

PRAGMA foreign_keys = ON;

CREATE TABLE alunos (
    id_aluno  INTEGER PRIMARY KEY AUTOINCREMENT,
    nome      TEXT    NOT NULL,
    curso     TEXT    NOT NULL,
    email     TEXT    NOT NULL
);

CREATE TABLE emprestimos (
    id_emprestimo   INTEGER PRIMARY KEY AUTOINCREMENT,
    id_aluno        INTEGER NOT NULL,
    id_exemplar     INTEGER NOT NULL,
    data_emprestimo TEXT    NOT NULL,
    data_devolucao  TEXT,   -- NULL = em aberto
    FOREIGN KEY (id_aluno)    REFERENCES alunos(id_aluno),
    FOREIGN KEY (id_exemplar) REFERENCES exemplares(id_exemplar)
);
AUTOINCREMENT = conta automático NOT NULL = obrigatório FOREIGN KEY = chave estrangeira

DML — Consulta

SELECT — Consultando Dados

-- Tudo de alunos
SELECT * FROM alunos;

-- Só nome e curso
SELECT nome, curso
FROM alunos;
-- Filtrar por curso
SELECT * FROM alunos
WHERE curso = 'Direito';
-- Ordem alfabética
SELECT * FROM alunos
ORDER BY nome ASC;
  • SELECT — escolhe as colunas
  • * — seleciona todas as colunas
  • FROM — de qual tabela
  • WHERE — filtra registros
  • ORDER BY ASC — A → Z (crescente)
  • ORDER BY DESC — Z → A (decrescente)
DML — Atualização e Exclusão

UPDATE e DELETE

✅ UPDATE correto

UPDATE exemplares
SET    status = 'Disponível'
WHERE  id_exemplar = 5;

⚠️ UPDATE perigoso

-- SEM WHERE — altera TODOS!
UPDATE exemplares
SET    status = 'Disponível';

✅ DELETE correto

DELETE FROM alunos
WHERE id_aluno = 5;

⛔ PERIGO: DELETE sem WHERE

Remove TODOS os registros da tabela. Não há como desfazer!

Consultas Avançadas

JOIN — Juntando Tabelas

SELECT
    alunos.nome,
    livros.titulo,
    emprestimos.data_emprestimo,
    emprestimos.data_devolucao
FROM emprestimos
JOIN alunos      ON emprestimos.id_aluno    = alunos.id_aluno
JOIN exemplares  ON emprestimos.id_exemplar = exemplares.id_exemplar
JOIN livros      ON exemplares.id_livro    = livros.id_livro;

🌉 JOIN funciona como uma ponte entre tabelas. O ON define qual coluna conecta as duas tabelas — sempre conectando IDs iguais.

Consultas Avançadas

IS NULL — Empréstimos em Aberto

SELECT
    alunos.nome,
    livros.titulo,
    emprestimos.data_emprestimo
FROM emprestimos
JOIN alunos     ON emprestimos.id_aluno    = alunos.id_aluno
JOIN exemplares ON emprestimos.id_exemplar = exemplares.id_exemplar
JOIN livros     ON exemplares.id_livro    = livros.id_livro
WHERE emprestimos.data_devolucao IS NULL;

⚠️ Use IS NULL (nunca = NULL). NULL não é um valor normal — é ausência de valor. Comparar com = nunca funciona no SQL.

Agregação

COUNT e GROUP BY

-- Total de alunos
SELECT COUNT(*) AS total_alunos
FROM alunos;
-- Empréstimos por aluno
SELECT
    alunos.nome,
    COUNT(emprestimos.id_emprestimo)
        AS quantidade
FROM alunos
LEFT JOIN emprestimos
    ON alunos.id_aluno = emprestimos.id_aluno
GROUP BY alunos.id_aluno, alunos.nome;

Lógica Condicional

CASE — Condições no SQL

SELECT
    alunos.nome,
    livros.titulo,
    emprestimos.data_emprestimo,
    CASE
        WHEN emprestimos.data_devolucao IS NULL THEN 'Em aberto'
        ELSE                                                  'Devolvido'
    END AS situacao
FROM emprestimos
JOIN alunos     ON emprestimos.id_aluno    = alunos.id_aluno
JOIN exemplares ON emprestimos.id_exemplar = exemplares.id_exemplar
JOIN livros     ON exemplares.id_livro    = livros.id_livro;

🤔 Em linguagem simples: "Se a data de devolução estiver vazia → mostre Em aberto. Caso contrário → mostre Devolvido."
